# Farroupilha Domination

Este projeto trata de um jogo Tower Defense no formato 2D cujo objetivo é simular de forma "irreverente", a Guerra dos Farrapos, em uma realidade alternativa.

A **Guerra dos Farrapos**, também chamada de **Revolução Farroupilha**, foi a mais longa guerra civil do Brasil. O conflito ocorreu entre 1835 e 1845, na província de São Pedro do Rio Grande do Sul (atual Rio Grande do Sul), envolvendo tropas farroupilhas, lideradas por estancieiros locais, e as forças do Império do Brasil.

Basicamente, o game consiste em colocar o Xirú (player) como patrão das tropas farroupilhas, posicionando Gaúchos para frear os ataques da Força Imperial. Conforme o avanço de fases, os farrapos avançam para os estados de Santa Catarina, Paraná e São Paulo, até chegar ao Rio de Janeiro. Vale ressaltar que a moeda do jogo é o PIla, e através dela que os Gaúchos (torres) são adquiridos.
